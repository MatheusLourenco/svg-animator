# SVG Animation with Anime.js

This project is a simple example of SVG animations using the [Anime.js](https://animejs.com/) library. You can view and edit vector animations in your browser quickly and easily.

---

## Technologies

- HTML5
- CSS3
- JavaScript (Anime.js)
- Vite

---

## 🚀 How to Run the Project

### 📌 Requirements:
- [Node.js](https://nodejs.org/) installed

### Install dependencies:
```bash
npm install
```

### Run the application:
Starts the local server at http://localhost:3000
```
npm start 
```

Starts the local server and watches for changes (manual refresh)
```
npm run dev	
```
